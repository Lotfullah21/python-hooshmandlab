# آموزش کامل برنامه‌نویسی با پایتون

به مستند رسمی دوره برنامه‌نویسی با پایتون خوش آمدید. در این مستند تمامی مفاهیم و مباحث تدریس شده در این دوره را پوشش می‌دهیم. هدف ما این است که شما پس از پایان این دوره بتوانید به راحتی برنامه‌های کاربردی با پایتون بنویسید.

## مقدمه‌ای بر برنامه‌نویسی

### برنامه‌نویسی چیست؟

برنامه‌نویسی فرایند نوشتن کدهایی است که به کامپیوتر دستور می‌دهد چه کاری انجام دهد. این دستورها به زبان‌هایی نوشته می‌شوند که کامپیوتر آن‌ها را متوجه شود.

### چرا برنامه‌نویسی مهم است؟

با برنامه‌نویسی می‌توان نرم‌افزار، وب‌سایت، اپلیکیشن موبایل و سیستم‌های هوشمند ایجاد کرد. همچنین، مهارت برنامه‌نویسی در بازار کار امروزی بسیار ارزشمند است.

## مبانی زبان پایتون

### متغیرها در پایتون

متغیرها در پایتون برای ذخیره داده‌ها استفاده می‌شوند. مثلاً:

```python
name = "احمد"
age = 25
print(name, age)
```

### انواع داده‌ها

پایتون از انواع مختلف داده‌ها پشتیبانی می‌کند مانند:

- رشته‌ها (Strings)
- اعداد صحیح (Integers)
- اعداد اعشاری (Floats)
- لیست‌ها (Lists)
- دیکشنری‌ها (Dictionaries)

### عملگرها در پایتون

عملگرها برای انجام عملیات ریاضی و منطقی استفاده می‌شوند. مثلاً:

```python
x = 5
y = 3
print(x + y)  # جمع
print(x - y)  # تفریق
```

## ساختارهای کنترلی

### شرط‌ها (if, else, elif)

برای کنترل جریان کد از شرط‌ها استفاده می‌شود. مثال:

```python
age = 20
if age >= 18:
    print("شما بزرگسال هستید")
else:
    print("شما کودک هستید")
```

### حلقه‌ها (for, while)

حلقه‌ها برای اجرای کد به تعداد دفعات مشخص استفاده می‌شوند.

```python
for i in range(5):
    print("سلام")
```

یا:

```python
x = 0
while x < 5:
    print(x)
    x += 1
```

## توابع در پایتون

### تعریف توابع

توابع بلوک‌هایی از کد هستند که برای انجام وظایف خاص نوشته می‌شوند.

```python
def greet(name):
    print("سلام", name)

greet("احمد")
```

### آرگومان‌ها و پارامترها

- **پارامتر:** متغیری که در تعریف تابع استفاده می‌شود.
- **آرگومان:** داده‌ای که هنگام فراخوانی تابع ارسال می‌شود.

## برنامه‌نویسی شی‌گرا (OOP)

### کلاس‌ها و اشیاء

کلاس قالبی برای ایجاد اشیاء است. مثال:

```python
class Car:
    def __init__(self, brand):
        self.brand = brand

car1 = Car("Toyota")
print(car1.brand)
```

### وراثت و چندریختی

- **وراثت:** امکان استفاده مجدد از کدهای کلاس والد.
- **چندریختی:** قابلیت استفاده از یک تابع با ورودی‌های متفاوت.

## کار با فایل‌ها

### خواندن از فایل

```python
with open("file.txt", "r") as file:
    content = file.read()
    print(content)
```

### نوشتن در فایل

```python
with open("file.txt", "w") as file:
    file.write("سلام دنیا")
```

## مدیریت خطاها

### استثناء‌ها و مدیریت آنها

برای جلوگیری از توقف برنامه در صورت خطا از مدیریت استثناء استفاده می‌کنیم:

```python
try:
    x = int(input("عدد وارد کنید: "))
except ValueError:
    print("لطفاً یک عدد صحیح وارد کنید")
```

## پروژه نهایی

### ساخت یک پروژه عملی در پایتون

در پایان این دوره شما یک پروژه عملی کامل خواهید ساخت که تمامی مفاهیم تدریس شده را شامل می‌شود. مثال پروژه‌ها:

- ساخت ماشین حساب
- ساخت اپلیکیشن مدیریت کارها
- ساخت چت‌بات ساده
